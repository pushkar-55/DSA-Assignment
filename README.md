## About
This repository contains solutions to 26 questions from the Recursion Practice Assignment. Each question is solved in a separate Java file using recursion.

## How to Run
1. Install the Java JDK.
2. Open the required `.java` file in a terminal.
3. Compile the file:

   `javac Q06_Factorial.java`

4. Run the program:

   `java Q06_Factorial`

Replace `Q06_Factorial` with the name of the question you want to run.

## Files
Each question has its own `.java` file, named according to its question number.
